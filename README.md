# kokoni-ec1-server

KOKONI EC1 3Dプリンター用コントローラーサーバー

プリンターのAndroidシステム上で軽量なHTTPエージェントを直接実行し、UART経由でプリンターのMCUと通信します。デスクトップGUIやcurlクライアントから `adb forward` 経由で印刷ジョブを制御できるようになります。

印刷ジョブはプリンター側で実行されます。ジョブ開始後、PCとの接続を切断しても、プリンターは印刷を続行できます。

## 概要

3DプリンタのAndroid基板の`/system/bin/`にkokoni_launcherとkokoni_webを設置し、実行する。

詳細な手順はdocsを参考にしてください。Windowsでの実行は適宜読みかえてください。

同時に使用することを想定しているGUIはこちら: https://github.com/nakonanya/kokoni-ec1-desktop

## 環境

開発環境はUbuntu24.04ですが、Windows11 proでも動作を確認しています。

## ディレクトリ構成

主なディレクトリとファイルの役割は以下の通りです：

- **`cmd/`** - 実行ファイルのエントリポイント
  - `kokoni-agent/` : プリンタ上で動くメインのHTTPエージェント。
  - `kokoni-launcher/` : エージェントの起動・管理を行うランチャー
- **`configs/`** - 印刷用プロファイル（Cura用プロファイルやマテリアル設定）
- **`docs/`** - 各種詳細なドキュメント。ここを見れば大体解決するでしょう。
- **`examples/`** - PC側で実行するスタートスクリプトの例（Windows/Linux用）。利用する際は自身の環境に合わせてパスやローカルIPを書き換えてください。
- **`internal/`** - プロジェクト内部で利用するGoパッケージ
- **`scripts/`** - ビルド、デプロイ、実行管理などのシェルスクリプト
- **ルート直下のファイル**
  - `kokoni_launcher`, `kokoni_web` : Android上で実行するためにビルドされたバイナリ（配置用）各自でビルドしてもしなくてもok。
  - `go.mod`, `go.sum` : Goモジュールの依存関係定義
